# SQL Business Analysis

## Overview

This folder contains the SQL analysis performed on the cleaned Google Play Store dataset.

SQL was used to answer key business questions related to product performance, customer engagement, pricing strategy, user adoption, and marketplace competitiveness.

The analysis supports data-driven decision-making by transforming raw business questions into actionable insights using SQL.

---

# SQL Concepts Applied

The analysis demonstrates practical use of the following SQL concepts:

- SELECT Statements
- Filtering (WHERE)
- ORDER BY
- GROUP BY
- Aggregate Functions
- CASE Statements
- Common Table Expressions (CTEs)
- Window Functions
- Subqueries
- Joins
- Ranking Functions

---

# Business Objectives

The SQL analysis aims to:

- Evaluate application performance.
- Measure customer engagement.
- Analyse user adoption.
- Compare monetisation strategies.
- Identify high-growth categories.
- Support executive decision-making.
