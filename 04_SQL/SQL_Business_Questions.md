# SQL Business Questions

## Objective

The objective of the SQL analysis is to transform raw Google Play Store data into actionable business insights by answering strategic business questions related to product performance, customer engagement, user adoption, pricing strategy, and marketplace competitiveness.

---

# Product Performance Analysis

The following business questions evaluate application performance across different categories.

### Business Questions

1. Which application categories contain the highest number of applications?
2. Which applications have achieved the highest number of installs?
3. Which applications receive the highest average ratings?
4. Which applications generate the highest customer engagement based on reviews?
5. Which categories demonstrate the strongest overall product performance?

---

# Customer Engagement Analysis

These questions focus on customer satisfaction and engagement.

### Business Questions

6. Which applications receive the highest number of customer reviews?
7. What relationship exists between ratings and review volume?
8. Which categories consistently receive high customer ratings?
9. Which content ratings attract the largest user base?
10. Which application categories generate the greatest customer engagement?

---

# User Adoption Analysis

These questions evaluate application popularity and market reach.

### Business Questions

11. Which applications have the largest user base?
12. Which categories dominate the marketplace based on installs?
13. What percentage of applications are free versus paid?
14. Which application categories show the greatest adoption potential?
15. Which Android versions support the highest number of applications?

---

# Pricing & Monetisation Analysis

These questions evaluate pricing strategies and revenue opportunities.

### Business Questions

16. How do paid applications perform compared with free applications?
17. Which categories have the highest average application prices?
18. Does application price influence customer ratings?
19. Which pricing ranges maximise user adoption?
20. Which product categories present the strongest monetisation opportunities?

---

# Marketplace Intelligence

These questions support strategic decision-making.

### Business Questions

21. Which categories appear highly competitive?
22. Which market segments demonstrate growth potential?
23. Which categories should receive additional investment?
24. Which applications require product improvement despite high visibility?
25. Which business opportunities can be identified through marketplace analysis?

---

# Expected Business Outcomes

The SQL analysis supports stakeholders by enabling them to:

- Monitor product performance.
- Evaluate customer engagement.
- Understand user adoption behaviour.
- Optimise pricing strategies.
- Identify marketplace growth opportunities.
- Support evidence-based product decisions.
