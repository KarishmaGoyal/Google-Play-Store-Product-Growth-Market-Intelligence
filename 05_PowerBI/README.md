# 📊 Power BI Dashboard

## Overview

This folder contains the interactive Power BI dashboard developed for the **Google Play Store Product Growth & Marketplace Intelligence** project.

The dashboard transforms cleaned application data into executive-level insights, enabling stakeholders to monitor marketplace performance, evaluate customer engagement, analyse pricing strategies, and identify product growth opportunities.

---

# Dashboard Objectives

The dashboard is designed to help stakeholders:

- Monitor key business KPIs.
- Analyse product performance.
- Measure customer engagement.
- Evaluate marketplace competitiveness.
- Compare monetisation strategies.
- Support strategic decision-making.

---

# Dashboard Features

The dashboard includes interactive visualisations for:

- Executive KPI Summary
- Product Performance
- Category Analysis
- Customer Engagement
- User Adoption
- Pricing Analysis
- Marketplace Intelligence
