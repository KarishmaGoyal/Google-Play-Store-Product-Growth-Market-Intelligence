# 🔗 Data Model

## Objective

The data model provides the foundation for accurate reporting by organising cleaned datasets into a structured format that supports efficient calculations, filtering, and interactive visualisations within Power BI.

---

# Data Modelling Approach

The Power BI data model was designed to:

- Organise application data into an analytics-ready structure.
- Enable accurate KPI calculations.
- Support interactive filtering across visuals.
- Improve dashboard performance.
- Reduce data redundancy.

---

# Primary Dataset

The primary analytical dataset consists of cleaned Google Play Store application data prepared using Power Query.

Key business attributes include:

- Application
- Category
- Rating
- Reviews
- Installs
- Type
- Price
- Content Rating
- Genres
- Last Updated
- Android Version

---

# Modelling Principles

The following principles were followed during data modelling:

- Appropriate data types assigned to each column.
- Duplicate application records removed before modelling.
- Numerical fields prepared for aggregation.
- Date fields converted into date format.
- Business-friendly column names maintained.
- Data prepared for DAX calculations and dashboard reporting.

---

# Business Benefits

A well-structured data model enables:

- Accurate KPI calculations
- Consistent filtering across reports
- Faster dashboard performance
- Reliable business insights
- Improved scalability for future enhancements

---

# Outcome

The final data model provides a clean and reliable foundation for DAX calculations, interactive dashboards, and executive-level reporting.
