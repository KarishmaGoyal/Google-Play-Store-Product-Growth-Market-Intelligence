# Business Questions

## Project: Google Play Store Product Growth & Marketplace Intelligence

This document outlines the key business questions that guide the analysis and support data-driven product and business decisions.

---

## 1. Marketplace Performance

1. Which application categories generate the highest number of installs?
2. Which categories achieve the highest average user ratings?
3. Which categories contain the largest number of applications?
4. Which categories demonstrate the greatest market share based on installs?
5. Which categories present the highest growth potential?

---

## 2. Product Performance

1. Which applications consistently outperform competitors based on installs, ratings, and reviews?
2. Which product characteristics contribute most to application success?
3. Which application categories have the strongest overall product performance?
4. Which applications require improvement despite high visibility?
5. How does application size influence product performance?

---

## 3. Customer Behaviour

1. Is there a relationship between user ratings and application installs?
2. Does review volume influence customer adoption?
3. Which content ratings attract the largest user base?
4. How do customer preferences differ across application categories?
5. Which factors have the greatest influence on user engagement?

---

## 4. Monetisation Strategy

1. Do free applications outperform paid applications?
2. Which pricing ranges maximise user adoption?
3. Which application categories demonstrate the strongest monetisation potential?
4. How does pricing influence customer ratings?
5. Which pricing strategy should developers adopt to maximise business performance?

---

## 5. Market Intelligence

1. Which categories are highly competitive?
2. Which market segments appear underserved?
3. Which product categories offer the greatest business opportunities?
4. Where should developers focus future investments?
5. Which application categories should receive strategic growth initiatives?

---

## 6. Executive KPIs

1. What is the total number of applications available?
2. What is the total number of installs across all applications?
3. What is the average application rating?
4. What percentage of applications are free versus paid?
5. Which business KPIs should executives monitor regularly to evaluate marketplace performance?

---

## Expected Outcome

The analysis should provide actionable insights that enable stakeholders to:

- Improve product performance
- Optimise marketplace growth
- Enhance user experience
- Strengthen monetisation strategies
- Support evidence-based business decision-making
