# Dataset Overview

## Dataset Name

Google Play Store Apps Dataset

---

## Dataset Source

Kaggle

---

## Dataset Purpose

The dataset contains application-level information from the Google Play Store and is used to analyse product performance, customer behaviour, marketplace competition, pricing strategies, and business growth opportunities.

---

## Dataset Scope

The dataset includes application metadata such as:

- Application Name
- Category
- Rating
- Number of Reviews
- Number of Installs
- Price
- Application Size
- Content Rating
- Genres
- Last Updated Date
- Android Version
- Current Version

---

## Intended Business Use

This dataset will be used to:

- Evaluate application performance.
- Analyse customer engagement and adoption.
- Measure marketplace competitiveness.
- Assess pricing and monetisation strategies.
- Develop business intelligence dashboards.
- Generate actionable business recommendations.

---

## Dataset Limitations

The dataset represents a snapshot of Google Play Store applications and may contain missing values, duplicate records, inconsistent formats, or outdated information that require preprocessing before analysis.
