# Dataset Overview

## Project

**Google Play Store Product Growth & Marketplace Intelligence**

---

# Dataset Description

This project utilises publicly available Google Play Store datasets to analyse application performance, customer engagement, marketplace competitiveness, pricing strategies, and product growth opportunities. The datasets provide comprehensive application metadata and user review information, enabling end-to-end product analytics and business intelligence.

---

# Dataset Source

- **Source:** Kaggle
- **Publisher:** Google Play Store Dataset
- **Format:** CSV
- **Data Type:** Structured Data

---

# Dataset Components

The project uses two datasets:

## 1. googleplaystore.csv

Contains application-level metadata including:

- Application Name
- Category
- Rating
- Reviews
- Installs
- Size
- Type (Free/Paid)
- Price
- Content Rating
- Genres
- Last Updated
- Current Version
- Android Version

---

## 2. googleplaystore_user_reviews.csv

Contains customer review information including:

- Application Name
- Translated Review
- Sentiment
- Sentiment Polarity
- Sentiment Subjectivity

---

# Business Purpose

The datasets support product and business analytics by enabling stakeholders to:

- Evaluate application performance.
- Measure customer engagement.
- Analyse user adoption patterns.
- Compare monetisation strategies.
- Assess marketplace competitiveness.
- Identify product growth opportunities.
- Support data-driven product decisions.

# Dataset Limitations

The datasets represent a historical snapshot of Google Play Store applications and contain several data quality issues that require preprocessing before analysis, including duplicate records, missing values, inconsistent formatting, and non-standard data types.

---

# Next Step

The datasets undergo data quality assessment and Power Query (ETL) transformations before being used for SQL analysis, KPI development, and Power BI dashboard creation.
